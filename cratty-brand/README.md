# Cratty brand assets

## Colors
- Rust      #E8643A  shell, claws, legs, eyes
- Phosphor  #7EE787  prompt, cursor and "tty" in the wordmark
- Phosphor Dark #1A7F37  "tty" and cursor in the light-background logo (readable on white)
- Ink       #15110E  icon background, terminal screen
- Bone      #F3EDE6  wordmark on dark backgrounds

Wordmark: JetBrains Mono ExtraBold (SIL OFL), converted to outlines in the SVG files.

## Files
- logo/cratty-logo-dark.*        for dark backgrounds (light text)
- logo/cratty-logo-light.*       for light backgrounds (dark text)
- logo/cratty-logo-on-dark-bg.*  with its own dark background
- mark/                          the crab mark alone, transparent
- icons/                         app icon PNG 16-1024, cratty.ico (Windows), cratty.icns (macOS), favicon.ico/svg
